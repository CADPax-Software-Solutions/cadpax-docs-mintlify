This quickstart takes you from a CADPax RevCloud Plus installation to a labelled revision cloud in Vectorworks. Use a sample file so you can test the workflow without changing a live issue set.

<Steps>
  <Step title="Install the plug-in">
    Follow [Install RevCloud Plus](/revcloud-plus/installation), including the workspace and license checks. Verify that your supplied package supports the Vectorworks version you are using.
  </Step>
  <Step title="Create a revision cloud">
    Select the **RevCloud Plus** tool, draw a path around a test change and enter a revision number or letter. Follow [Create your first revision cloud](/revcloud-plus/first-cloud).
  </Step>
  <Step title="Adjust the annotation">
    Use **Settings v2** to show or hide the cloud and label, choose a bubble shape, and adjust cloud size and variation. See the [settings guide](/revcloud-plus/settings).
  </Step>
  <Step title="Review the sheet revision">
    If the active layer has a Vectorworks Title Block Border, inspect its revision records through the settings dialog. Read the [title block guide](/revcloud-plus/title-block) before making changes.
  </Step>
</Steps>

<Warning>
  The current **Copy from another title block/cloud** operation is unfinished. Use the normal Revision Data fields and the supported Add, Replace or Append actions instead.
</Warning>

For help with missing plug-ins, labels, title blocks and licensing, open [Troubleshooting](/revcloud-plus/troubleshooting).
