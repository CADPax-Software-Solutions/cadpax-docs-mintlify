## How to use these guides

1. Start with your product's **Installation** instructions and check supported Vectorworks versions.
2. Follow the first-use tutorial in a test drawing.
3. Use the feature references for specific controls and drawing workflows.
4. Consult troubleshooting and release notes if an option behaves differently than expected.

<Note>
  These guides are being prepared against source code and development notes. Compatibility, release-package contents and screenshots must be verified against the final customer build before public publication.
</Note>
