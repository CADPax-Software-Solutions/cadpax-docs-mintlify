These release notes reflect the CADPax source changelogs reviewed on 10 November 2026. The entries describe tracked development versions and do not, by themselves, confirm public availability or a production-tested customer distribution.

## RevCloud Plus object

### 0.11 (10 June 2026)

- Added a read-only **License Info** status entry.
- Added **Approved Class** graphic routing, with the non-active class taking precedence for inactive clouds.
- Added approved-class controls to the object settings and manager workflows.
- Changed date autofill and guidance to **dd/mm/yy**.
- Improved user-initials autofill handling across Windows and macOS.

### 0.10 (7 May 2026)

- Improved launching the companion manager from encrypted plug-in builds.
- Aligned the settings dialog with the current shared issue/revision library.

### 0.09 (30 April 2026)

- Improved encrypted package import paths and dialog resources.

### 0.08 (22 April 2026)

- Standardised the public product and plug-in filename as **RevCloud Plus**.

## Companion manager

### 0.1.1 (7 May 2026)

- Improved encrypted manager launch compatibility.

### 0.1.0 (24 April 2026)

- Initial companion manager scaffold.

## Known limitations

- Copy-from-another-title-block and copy-from-another-revision-cloud actions are incomplete.
- Label suffix rendering and combined issue/revision labels are not complete.
- Full Vectorworks 2026 packaging and production release validation remain outstanding in the reviewed sources.
- Legacy conversion must be tested in a copy of the drawing before use.
