RevCloud Plus currently uses a license-file validation workflow. The plug-in also provides a read-only **License Info** entry in the Object Info palette to help diagnose activation problems.

## Check license status

1. Open a Vectorworks document that contains a RevCloud Plus object.
2. Select the object and inspect the **License Info** entry in its Object Info palette.
3. If the plug-in reports an invalid or missing license, retain the message and confirm which Vectorworks version and CADPax package you installed.
4. Contact CADPax through [cadpax.com](https://cadpax.com/) for the approved license file and activation instructions.

<Warning>
Customer-facing license delivery instructions, exact license-file location, licence renewal process and transfer policy have not yet been verified for the commercial release. Do not use developer key-generation instructions or files as an activation procedure.
</Warning>

## Compatibility

| Platform | Current evidence |
| --- | --- |
| **Vectorworks 2025** | Listed in the current RevCloud Plus plug-in metadata. |
| **Vectorworks 2026** | A credentialled encrypted object plug-in has been recognised by Vectorworks 2026; full release-package testing is still required. |
| **Other Vectorworks versions** | No verified compatibility claim is available in the reviewed source material. |

The final customer download should include an explicit compatibility list for the precise release package, including any difference between Windows and macOS.
